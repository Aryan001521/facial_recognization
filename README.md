# Real-Time Facial Emotion Recognition

## Features
- Real-time webcam emotion detection
- CNN model trained using TensorFlow
- Face detection using OpenCV Haar Cascade
- Predicts:
  - Angry
  - Disgust
  - Fear
  - Happy
  - Neutral
  - Sad
  - Surprise

## Tech Stack
- Python
- TensorFlow
- OpenCV
- NumPy

## Run

```bash
pip install -r requirements.txt
python main.py
